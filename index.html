📋 Etapas do Processamento

ℹ️ Como funciona?

  • Letras maiúsculas (A-Z): São deslocadas para a próxima letra maiúscula (Z vira A)
  • Letras minúsculas (a-z): São deslocadas para a próxima letra minúscula (z vira a)
  • Números e símbolos: Permanecem inalterados
